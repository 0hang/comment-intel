# 评论抽取 schema v0.1

对每条评论输出一个 JSON 对象。**只抽评论里真实存在的东西，宁缺勿造。**

```json
{
  "aweme_id": "视频ID（原样复制）",
  "i": 0,
  "text": "评论原文（原样复制，不改写）",
  "like": 123,
  "concerns": ["关注点"],
  "persona": "人群 或 null",
  "stance": "情绪立场",
  "metaphor": "隐喻/金句 或 null",
  "coping": ["应对策略"],
  "is_sarcasm": false,
  "is_ask": false,
  "is_win": false
}
```

## 字段规则

**concerns（关注点/焦虑点，0-2 个）**
评论真正在担心/关心的事。用 2-6 字短语，尽量复用下面已有词表；实在没有再新建。
已有词表：`AI替代人`、`学历贬值`、`读博价值`、`技术贬值`、`不会用工具`、`变现难`、`开源刷星`、`信息过载`、`圈子落后`、`同行竞争`、`职业选择`、`工具可信度`、`国内环境`、`生活成本`
纯玩梗、纯打招呼、纯夸奖 → 空数组 `[]`。

**persona（人群，最多 1 个）**
只在评论明确自述或强暗示时填。词表：`程序员`、`大学生`、`博士生`、`留学生`、`自媒体新人`、`职场人`、`创业者`、`家长`、`老师`。无线索填 `null`。

**stance（情绪立场，必填 1 个）**
`焦虑` | `认同` | `质疑` | `调侃` | `求助` | `分享成果` | `反驳` | `中立`

**metaphor（隐喻/金句）**
评论里把某事物比作别的东西、或高度凝练的金句。原样摘出（≤30 字）。没有填 `null`。
例：「传统命理学其实就是靠人力炼了几千年的大模型」、「放进冷冻=获得永生」

**coping（应对策略，0-2 个）**
评论提到的应对方法。词表：`学AI工具`、`退学`、`换圈子`、`做自媒体`、`变现`、`考公考编`、`躺平`、`转行`、`搞副业`、`读书深造`、`出国`。没有填 `[]`。

**is_sarcasm**
阴阳怪气/反讽。字面正向但实际负面 → `true`。
例：「挺好的，以后送外卖路上还能跟AI聊人生」→ true

**is_ask**
在提问、求教程、求资源、问怎么用 → `true`。这是内容缺口信号。

**is_win**
汇报自己做成了某事（涨粉、变现、跑通、上手） → `true`。这是正反馈信号。

## 输出格式

输出一个 JSON 数组，包含你负责的全部评论，每条一个对象。不要输出任何解释文字、不要包 markdown 代码块，直接输出 `[` 开头 `]` 结尾的 JSON。
